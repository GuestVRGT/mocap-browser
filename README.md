# mocap-browser 🐒

Browser body-tracking tool (MonkeMocap-inspired).

## Features
- Live cube preview with hands
- Ground clamp
- Default pose + free arm / hand rotation
- **Physics** (body can be moved by hands with momentum)
- Optional eye tracking + mouth tracking toggles
- Mouth frames copied from guest.lol (Face-4 style)

## Mouth assets
Located in `/mouths/` (from GuestVRGT/guest.lol):
- mouth_frame0.js … mouth_frame3.js
- mouths-data.js

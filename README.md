# Monke Hand Tracking Playground 🐱

Nyaaa~!! A silly original HTML playground inspired by gorilla-tag vibes.

## Features
- Webcam hand tracking via MediaPipe Hands
- Move your hand left/right/up/down → monke follows
- Pinch (thumb + index close) → little jump
- Mouse drag to look around the 3D world
- Live webcam preview in the corner (mirrored)

## How to play
1. Open the live page (GitHub Pages or just open index.html)
2. Allow camera access when the browser asks
3. Wave your hand in front of the camera and watch the brown monke blob move!

## Live demo
Once GitHub Pages is enabled (Settings → Pages → Deploy from main), it will be at:
https://guestvrgt.github.io/monke-hand-tracking-playground/

Or just download/open the `index.html` file locally (needs a local server or GitHub Pages for camera to work properly in some browsers).
